# YIMO Graphwar 2.0.0 notices

YIMO Graphwar is a modified version of Graphwar, an artillery game based on
mathematical functions.

The original Graphwar program and its original source are credited to Lucas
Catabriga Rocha and the upstream Graphwar contributors. The upstream project
is available at <https://github.com/catabriga/graphwar>.

This release contains YIMO modifications, including the responsive Swing
client, YIMO presentation, guided campaign, global graph mode, validated
network protocol, tournament service, and deployment tooling. Modified files
retain their applicable upstream copyright and GPL notices; new YIMO source
files are released under GPL-3.0-or-later.
